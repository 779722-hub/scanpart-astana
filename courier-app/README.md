# SCANPART · Приложение для курьеров (Expo / React Native)

Нативное Android-приложение курьера. Работает с бэкендом на **https://scanpart.kz**
(те же API, что использует админка). Отдельный проект — не влияет на сайт.

## Что умеет
- Вход курьера (логин/пароль, создаёт руководитель в админке → «Курьеры»).
- Список назначенных доставок на сегодня + **оптимальный маршрут** (заборы со
  складов → развоз) с **временем прибытия (ETA)** на каждую точку.
- Геолокация курьера как старт маршрута.
- Действия по доставке: «Начать забор» → «В путь к клиенту» (клиенту уходит
  4-значный **код получения** в WhatsApp) → ввод кода от клиента → «Подтвердить
  выдачу». Всё дублируется в админке.
- Карта 2ГИС с точками маршрута (при заданном ключе).

## Требования
- Node 18+, аккаунт Expo (бесплатно), Android-телефон.

## Запуск для разработки (быстрая проверка без сборки)
```bash
cd courier-app
npm install
npx expo start
```
Установите на телефон приложение **Expo Go** (Play Store) и отсканируйте QR из
терминала. Геолокация, экраны и статусы работают сразу; карта 2ГИС — после
добавления ключа (см. ниже).

## Настройка
`app.json` → `expo.extra`:
- `apiBaseUrl` — адрес бэкенда (по умолчанию `https://scanpart.kz`).
- `twogisMapKey` — ключ **2ГИС MapGL JS** (dev.2gis.ru). Без него карта покажет
  подсказку, остальное работает.

## Сборка APK для установки курьерам
```bash
npm install -g eas-cli
eas login
cd courier-app
eas build -p android --profile preview
```
По завершении EAS даст ссылку на **APK** — скачайте и установите на телефоны
курьеров (или раздайте ссылку). Профиль `production` (`app-bundle`) — для
публикации в Google Play.

## Как это связано с сайтом
- Курьеров и доставки создаёт руководитель в **Админка → Доставки / Курьеры**.
- Приложение ходит в `/api/courier/*` (вход, маршрут, смена статуса, проверка
  кода). Авторизация — сессионная кука (RN хранит её сам).
- Код получения отправляется клиенту автоматически, если на бэкенде заданы
  `WHATSAPP_TOKEN` + `WHATSAPP_PHONE_ID` (WhatsApp Cloud API). Иначе курьер
  отправляет код клиенту одним тапом (ссылка WhatsApp).

## Структура
```
App.tsx                 навигация (вход → маршрут → карта)
src/config.ts           apiBaseUrl / twogisMapKey из app.json
src/api.ts              клиент API (/api/courier/*)
src/auth.tsx            контекст авторизации
src/screens/LoginScreen.tsx
src/screens/RouteScreen.tsx    маршрут + доставки + действия + код
src/screens/MapScreen.tsx      карта 2ГИС (WebView MapGL)
```
